# AMDGPU code object V5 tracker

Gaps found by the [audit](std-amdgpu-abi-audit.html) of 2026-11-13,
re-audited on 2026-11-14 against `main` `81fbcba` after PRs #58 (merge
`53dac5b`, issue #12) and #44 (merge `38f2f60`, issue #8) merged. Hardware
evidence: the GPU tests [#45](https://github.com/itej89/rustinfer/issues/45)
and [#59](https://github.com/itej89/rustinfer/issues/59) passed on an MI350X
(gfx950) under ROCm 10.1 (10.1.0-3) on 2026-11-15 (UTC), results in
[#54](https://github.com/itej89/rustinfer/issues/54); gfx942 has not been run
([#61](https://github.com/itej89/rustinfer/issues/61)).
