# HIP runtime API ROCm 7.2 tracker

Gaps found by the [audit](std-hip-audit.html) of 2026-11-13, re-audited on
2026-11-14 against `main` `81fbcba` after PR
[#58](https://github.com/itej89/rustinfer/pull/58) (issue
[#12](https://github.com/itej89/rustinfer/issues/12), merge `53dac5b`) bound
the HIP runtime and PR #44 (merge `38f2f60`) moved its GPU tests onto that
binding. The binding's hardware test [#59](https://github.com/itej89/rustinfer/issues/59)
passed on an MI350X (gfx950) under ROCm 10.1 (10.1.0-3), HIP runtime major 7,
at `bb0ce2f`, the head PR #58 merged: 11 passed, results in
[#54](https://github.com/itej89/rustinfer/issues/54). gfx942 is not yet run;
that is [#61](https://github.com/itej89/rustinfer/issues/61), recorded as HIP-13.
Paths are under `crates/rustinfer-target-rocm/` unless named otherwise.
