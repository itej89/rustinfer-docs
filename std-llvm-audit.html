LLVM 23.1 audit

Audit of 2026-11-13, against the requirements.

Method. Read origin/main at ccf02b3: crates/rustinfer-kc/src/, its tests, scripts/ci/install_llvm.sh, Cargo.toml and ADR-007. Read open PR #44 (branch feat/8-amd-lowering, head 10b8b1b) for the items it implements; its CI run 43520689140 passed (lint, msrv, test, build, security), and its GPU test request #45 has not been run. Compared each item with the LLVM 23.1.0 text in specs/compiler/. No test was run locally. Test tags follow docs/testing.md (Verifies, Groundwork for, Reserved).

Result

The pinned link conforms: CI installs one exact 23.1 build, the binding refuses any other major, and the masked intrinsics and address spaces the Kernel IR relies on match the LangRef and AMDGPUUsage text. Nothing on main generates machine code. The AMDGPU target machine, the IR configuration it needs and the lld link all arrive with PR #44, whose host tests pass in CI but whose hardware run (#45) is outstanding. Gaps are on the tracker.
