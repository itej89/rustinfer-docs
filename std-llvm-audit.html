LLVM 23.1 audit

Audit of 2026-11-14, against the requirements; it replaces the audit of 2026-11-13, which read PR #44 before it merged.

Method. Read main at 81fbcba (after PR #44, merge 38f2f60, issue

8): crates/rustinfer-kc/src/ (mlir/llvm.rs, emit.rs, raw.rs,

mod.rs, lower.rs, lld_shim.cpp), build.rs, its tests, scripts/ci/install_llvm.sh, .github/workflows/ci.yml, Cargo.toml and ADR-007 (amended by #8). Read the result of GPU test #45 in #54: an MI350X (gfx950) under ROCm 10.1 (10.1.0-3), 2026-11-15 (UTC), at 821a57e, PR #44 before its rebase onto #58's target. Compared each item with the LLVM 23.1.0 text in specs/compiler/. No test was run locally. Test tags follow docs/testing.md (Verifies, Groundwork for, Reserved).

Result

Every R1 item conforms on main: one exact 23.1 build is installed and linked, another major is refused, and since PR #44 the AMDGPU target machine, the IR configuration it needs and the in-process lld link generate the shared code objects the HIP loader takes. On gfx950 that output loaded and computed exactly (#45, #59, results in #54). The gfx942 output has been seen only as disassembly on the host; its hardware run is #61 (LLVM-5), which also re-runs #45 on gfx950 at main. Gaps are on the tracker.

Read from the rustinfer tree at commit 53af206 2026-11-19, branch detached of github.com/itej89/rustinfer. Every claim here was read from the source unless a page says otherwise. GPU results are the owner's hardware runs, cited by issue (#54); this site itself runs nothing.
