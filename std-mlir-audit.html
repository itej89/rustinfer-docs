Result

Everything main emits is valid against the LLVM 23 definitions: the IRDL-defined dialect, the vector operations it rewrites into (with the masked forms used exactly where the definitions allow out-of-bounds indices), the host pass names and the llvm translation. The gpu, amdgpu and rocdl path is complete on the host in PR #44, but the operand layouts it assumes for amdgpu.mfma, which the definition delegates to the CDNA ISA, are proven only by the hardware run of #45. The MXFP4 operations are not written yet. Gaps are on the tracker.
